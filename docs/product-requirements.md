# Product requirements

## Core goals

- Provide a secure local command center for personal workflows
- Keep the product usable without a network connection
- Support file import, indexing, and local metadata persistence
- Create a foundation for future mobile, Linux, and remote sync features

## Non-functional requirements

- Cross-platform desktop shell
- Offline-first data model
- Explicit distinction between local and synced data
- No secret material committed to source control
- Architecture should support future platform expansion without major rewrites
